# robot_bridge — робот ↔ «Роботи» на сайті

Bridge запускається біля робота (ПК, ноутбук чи Jetson, з'єднаний з роботом кабелем) і сам підключається до
бекенду Єви на Render. Сайт і робот напряму одне одного не бачать, тож порти відкривати не треба й робот може
бути в будь-якій мережі.

```
[Робот] ←Unitree SDK2 / Ethernet→ [bridge.py] ──wss──→ [server/robots.py на Render] ←──wss── [сайт: телефон / ноут / геймпад]
```

## Запуск

```bash
pip install websockets
# без робота — емулятор, друкує команди в консоль:
python bridge.py --robot mock-dog --id go2-01 --name "Go2"

# справжній Go2 (потрібен доступ до SDK, тобто EDU):
pip install unitree_sdk2py          # або з github.com/unitreerobotics/unitree_sdk2_python
python bridge.py --robot go2 --iface eth0 --id go2-01 --name "Go2"

# гуманоїд (G1 / R1):
python bridge.py --robot r1 --iface eth0 --id r1-01 --name "R1"
```

| Параметр | Що це |
|---|---|
| `--robot` | `go2`, `r1`, `g1`, `mock-dog`, `mock-humanoid` |
| `--iface` | мережевий інтерфейс, через який ПК бачить робота (`ip a` / `ifconfig`; підмережа `192.168.123.x`) |
| `--id` | унікальний `robot_id`; той самий id після перезапуску — замок оператора зберігається |
| `--name` | назва на сайті |
| `--relay` | за замовчуванням бекенд на Render; локально — `ws://localhost:8000/ws/robot` (або змінна `ROBOT_RELAY`) |
| `--token` | лише якщо на Render задано `ROBOT_TOKEN` (або змінна `ROBOT_TOKEN`); інакше не потрібен |

## Безпека — усе тут, а не на сервері

- **Ліміти швидкості** задані в адаптері (`adapters.py`, `max_vx/max_vy/max_yaw`): що б не прийшло з сайту, bridge обрізає. Гуманоїд повільніший за собаку.
- **Deadman 0,35 с**: немає команд руху — робот зупиняється. Відпустили джойстик, закрили вкладку, пропав інтернет — зупинка.
- **Зник зв'язок із сервером** — стоп і перепідключення кожні 2 с.
- Перед дією (встати, сісти…) робот спершу зупиняється.

Перший тест справжнього робота — на вільному просторі, з людиною біля кнопки СТОП (на сайті СТОП може натиснути будь-хто, не лише той, хто керує).

## Новий робот

Додайте клас у `adapters.py` з методами `connect`, `move(vx, vy, yaw)`, `stop`, `action(name)`, списком `actions`
і лімітами, і рядок у `make_adapter`. Сайт сам намалює кнопки для його `actions` — міняти фронт не треба.

**R1:** `HumanoidAdapter` бере `LocoClient` гуманоїдів Unitree (як у G1). Назви методів для R1 ще не перевірені на
роботі: якщо SDK підключається, а якась дія падає — поправте таблицю в `HumanoidAdapter.action()` за прикладами SDK.
Версія Basic може взагалі не відкривати SDK; тоді треба уточнювати в Unitree чи дилера.
